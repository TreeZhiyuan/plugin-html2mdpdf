# 网页剪藏与 DOM 清理助手

这是一个基于 Chrome Manifest V3 的本地插件项目，支持：

- 在网页上悬停查看元素边界，点击隐藏元素，并按后进先出撤销。
- 框选多个正文或任意容器作为导出区域，再次点击已选区域可取消选择。
- 将当前可见内容转换为 Markdown 文件。
- 注入打印样式并打开系统打印对话框，可选择“另存为 PDF”。

Markdown 导出使用 `libs/markitdown-html.js` 对项目中的 Turndown 做了浏览器端扩展，移植了 Microsoft MarkItDown 的 HTML 清洗与特殊元素规则，包括脚本/样式移除、链接协议过滤与路径转义、懒加载图片、Data URI 截断、复选框、下划线、删除线和表格。表格中的表头、表体、表尾、空单元格与单元格内格式均可转换；HTML 合并单元格会展开为占位列。具体对应关系见 [MarkItDown HTML 转 Markdown 移植说明](docs/markitdown-html-port.md)。

## 安装

1. 打开 Chrome 的 `chrome://extensions`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本目录。
4. 打开任意普通网页，点击工具栏中的插件图标开始使用。

插件不需要构建步骤，目录中的 `libs/turndown.js` 是随项目一起提供的离线依赖。

## 使用顺序

先开启“元素隐藏模式”清理不需要的内容；如只想导出页面的一部分，再开启“框选导出区域”并连续点击一个或多个正文容器。再次点击已选区域可以取消它。之后可以导出 Markdown，或打开打印对话框并选择 PDF。

Chrome 的 `chrome://`、扩展商店和部分受保护页面不允许注入内容脚本，因此这些页面上插件操作会提示不可用。
